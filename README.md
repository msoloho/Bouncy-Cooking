# Bouncy Pizzery
This game was made for the Hackclub Haven Ottawa Game Jam!!

Created by [msoloho](https://github.com/msoloho/), [BoltyPlays](https://github.com/BoltyPlays), and [avilldev](https://github.com/avilldev).

## The Vision
It is a pizzeria cooking game in which all elements of it are bouncy! If you drop something, you're COOKED (heh, get it, like cooking...). No but actually, it will bounce in the kitchen, and become really chaotic. The customers are fellow organizers of the event. We also have a roomba that is cleaning up our kitchen; if it touches any of the ingredients, you lose it!
